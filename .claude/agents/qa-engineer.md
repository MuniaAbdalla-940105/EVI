journeys, unit/integration below). Cover the core commerce paths: browse, filter by size and color,
product page, size chart, add to cart, checkout, order confirmation email, returns. Include
accessibility checks (axe), mobile viewports, RTL/LTR if localized, slow network, and empty/error states.
Report defects with steps, expected vs actual, and severity.
