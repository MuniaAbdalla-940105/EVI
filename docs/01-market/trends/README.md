# Trends

Dated, sourced trend reports, one file per topic per research run:
`YYYY-MM-<topic>.md`, e.g. `2026-10-womenswear-ss27.md`, `2026-10-ecommerce-ux.md`.

Produced by `/trend-research`. Each report lists its sources with access dates and says how
confident each trend is (seen in 1 source vs. many). Older reports stay as history.
Design, brand, product, and UX work cites the latest relevant report.
