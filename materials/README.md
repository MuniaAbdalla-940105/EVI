# Materials library

Reusable fabrics and trims, shared across products. Products reference them by ID instead
of repeating specs.

| Path | Purpose |
| --- | --- |
| `fabrics/FAB-###-slug.md` | One fabric: composition, construction, weight, test results, certificates, suppliers |
| `trims/TRM-###-slug.md` | Buttons, zips, threads, labels, interlinings, packaging materials |

Copy `fabrics/_template.md` or `trims/_template.md`. Never claim a certificate you don't have on file.
